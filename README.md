# สมุดเงินของครรชิต · Kanchit's Bankbook

เว็บสมุดบัญชีส่วนตัวและบัญชีสำหรับนักพัฒนาเกม โทนน้ำเงินเข้มและเหลือง ใช้ HTML/CSS/JavaScript แบบ ES Modules ไม่มีขั้นตอน build และไม่มีข้อมูลส่วนตัวใน repository

## เปิดบน GitHub Pages

1. ใน repository `Kanchitfrank/Bankbook-` เปิด **Settings → Pages**
2. เลือก **Deploy from a branch**, branch **main**, folder **/(root)** แล้ว Save
3. ใช้ลิงก์ที่ GitHub แสดงหลัง deployment สำเร็จ แอปใช้ relative paths จึงรองรับชื่อ repository ที่ลงท้ายด้วยขีด

การตั้งค่า Pages ยังต้องทำด้วยตนเองตามที่เจ้าของร้องขอ ไม่มี workflow ที่เปิดใช้งาน hosting ให้อัตโนมัติ

## การใช้งาน

- **บัญชีของฉัน**: เพิ่มธนาคาร เงินสด หรือกระเป๋าดิจิทัล กำหนดยอดเริ่มต้นเอง คลิกบัญชีเพื่อดูประวัติ แก้ไขและลบได้
- **รายการเงิน**: รายรับและรายจ่าย รองรับสตางค์ อ่าน SMS ให้ตรวจยอด/ประเภทก่อนเลือกหมวดและบันทึก ไม่แสดงช่องโปรเจกต์เกมหรือบัญชีปลายทาง
- **พัฒนาเกม**: โปรเจกต์มีรูปปก สถานะ วันที่เผยแพร่ งบ ราคา และรายละเอียด คลิกเข้าแท็บบัญชีเกมเพื่อเพิ่มต้นทุน/รายรับโดยตรง เลือกเชื่อมบัญชีเงินจริงได้ ระบบสร้างรายการเงินให้ครั้งเดียว การแก้ไขไม่หักซ้ำ
- **Wishlist / ยอดขาย**: กด **อัปเดตสถิติ** ใส่วันที่ ยอดเข้าชมสะสม Wishlist ปัจจุบัน และยอดขายสะสม แก้ไข/ลบแต่ละวันที่บันทึกได้ ตัวเลขสถิติไม่สร้างรายรับอัตโนมัติ
- **แผนพัฒนา**: เพิ่มงาน ชั่วโมงที่เหลือ และกำหนดเสร็จ ผู้ช่วยคำนวณจากชั่วโมงต่อสัปดาห์กับวันเผื่อทดสอบ ไม่ทำนายผลตลาด
- **รีวิว**: เพิ่มเองหรือนำเข้า Steam reviews JSON จัดกลุ่มประเด็นจากคำสำคัญไทย/อังกฤษ กดเพิ่มประเด็นเป็นแผนงานได้ ไม่ใช้บริการ AI ภายนอก
- **ส่วนลด**: จำลองราคาสุทธิและยอดขายที่ต้องเพิ่ม คำนวณช่วงหลังวันขาย/ส่วนลด/ขึ้นราคา 30 วันสำหรับส่วนลดปกติ ต้องตรวจสิทธิ์จริงใน Steamworks โดยเฉพาะส่วนลดเปิดตัวและ Seasonal Sales
- **หนี้สิน**: ระบุชื่อผู้ให้ยืม ประเภทหนี้ เงินต้น ดอกเบี้ยและวันคืน บันทึกยอดคืนโดยแยกเงินต้นจากดอกเบี้ย
- **เป้าหมาย**: รูปและรายละเอียด คลิกเข้าไปดูแผนเก็บรายเดือน/รายวัน ยอดกันเงินไม่ใช่การหักเงินจริง
- **บิลประจำ**: แก้จำนวน ยกเลิก และกดจ่ายแล้วได้ ไม่มีการตัดบัญชีอัตโนมัติ ส่งออก `.ics` เพื่อนำเข้าปฏิทินได้

## ข้อมูลและความเป็นส่วนตัว

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์/โดเมนนั้นเท่านั้น คอมและมือถือเปิดลิงก์เดียวกันได้ แต่ข้อมูล **ยังไม่ซิงก์อัตโนมัติ** ใช้ส่งออก/นำเข้า JSON เพื่อย้ายข้อมูล รองรับ CSV สำหรับรายการเงิน รูปจะถูกย่อก่อนบันทึก อย่า commit ไฟล์สำรองข้อมูลการเงินเข้า Git

รุ่นนี้ล้างข้อมูลทดสอบจากคีย์ `kornchit-notebook-v1` ครั้งเดียวตามคำขอ แล้วใช้คีย์ `kanchit-bankbook-v2` ข้อมูลใหม่ไม่ถูกล้างเมื่อเปิดแอปซ้ำ การล้างข้อมูลในหน้าตั้งค่าย้อนกลับได้ในแท็บเดียวกันก่อนปิดหน้า/แก้ไขถัดไป

ถ้าจะซิงก์ข้ามอุปกรณ์ ควรเพิ่มฐานข้อมูลพร้อมล็อกอิน แยกข้อมูลแต่ละผู้ใช้ และสำรองฝั่งเซิร์ฟเวอร์ GitHub Pages ไม่มีฐานข้อมูลหรือ API backend มาให้

## เชื่อมต่อภายนอก

### รีวิว Steam (เตรียมตัวเชื่อมไว้ ยังไม่ deploy)

มีตัวอย่าง Cloudflare Worker ที่ `integrations/steam-reviews-worker.mjs` โดยใช้ endpoint รีวิวสาธารณะของ Steam

1. Deploy Worker ในบัญชีของคุณ
2. ตั้ง `ALLOWED_ORIGIN` ให้ตรง origin ของเว็บ เช่น `https://kanchitfrank.github.io` (ไม่มี path และไม่มี / ท้าย)
3. ตั้ง secret `API_TOKEN` ด้วยค่าสุ่มที่คุณสร้างเอง
4. หน้า **ข้อมูลและการเชื่อมต่อ** ใส่ URL ของ Worker และโทเคน
5. ใส่ Steam App ID ในเกม แล้วกด **ดึงรีวิว Steam** ในแท็บรีวิว ดึงได้สูงสุด 100 รีวิวล่าสุดต่อครั้ง ไม่ใช่รีวิวทั้งหมด

โทเคนอยู่ใน sessionStorage ของแท็บ ไม่รวมในไฟล์สำรอง Worker ตรวจ origin และ bearer token ก่อนเรียก Steam ไม่มีการตั้งค่า Cloudflare หรือกุญแจใดไว้ใน repository

### ยอดขายและ Wishlist Steamworks

Steam มี [IPartnerFinancialsService](https://partner.steamgames.com/doc/webapi/IPartnerFinancialsService) ที่ต้องใช้ Publisher Key พร้อมสิทธิ์ Financial ต้องทำ backend เพิ่มพร้อมแปลงรายงาน วันที่ และสกุลเงินก่อนซิงก์ รุ่นนี้ยัง **ไม่เชื่อมยอดขาย/Wishlist อัตโนมัติ** ห้ามใส่ Publisher Key ใน JavaScript หรือ repository สาธารณะ

### ธนาคาร กองทุน ปฏิทิน

- การอ่านบัญชีธนาคารต้องผ่าน API/ผู้ให้บริการที่ได้รับสิทธิ์และความยินยอม แอปยังไม่ได้เชื่อมธนาคาร [Your Data](https://www.bot.or.th/th/financial-innovation/digital-finance/open-data/Your_Data_Project.html)
- [SEC Fund Check](https://fundcheck.sec.or.th) เป็นลิงก์ค้นข้อมูล ไม่มีการดึง NAV หรือจัดอันดับกองทุนสด
- `.ics` เป็นการนำเข้าปฏิทินด้วยตนเอง ถ้าส่งออกซ้ำให้ตรวจบิลซ้ำในแอปปฏิทิน
- แอปแสดงคำเตือนเมื่อเปิดหน้า ไม่ส่ง push notification ขณะปิดแอป

## ตรวจและพัฒนา

ต้องมี Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ

```sh
node --test test.mjs
node tools/serve.mjs
```

เปิด `http://127.0.0.1:4173` อย่าเปิด `index.html` โดยตรงผ่าน `file://` เพราะเบราว์เซอร์อาจบล็อก ES Modules

ผลคำนวณสินเชื่อและคืนหนี้เป็นประมาณการแบบลดต้นลดดอก อัตราคงที่ ไม่รวมค่าธรรมเนียม ไม่ใช่ผลอนุมัติสินเชื่อ คำแนะนำการขายเกมเป็นแผนจากข้อมูลผู้ใช้ ไม่รับประกันยอดขาย
